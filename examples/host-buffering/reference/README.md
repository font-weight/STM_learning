# Необязательный эталон после собственной попытки

`stream_reference.c` — полный небольшой answer key к host-упражнению L10. Он нужен для проверки того, что сами тесты удовлетворимы, и для сравнения **после** собственной реализации. По умолчанию Make собирает `student.c`; урок не вставляет этот эталон вместо задания.

До открытия файла:

1. Запиши инварианты и вручную прогони очередь ёмкостью 2
2. Сделай собственную реализацию и запусти тесты
3. Зафиксируй конкретное расхождение, которое хочешь проверить

После сравнения закрой эталон и восстанови очередь самостоятельно. Прохождение oracle не является прохождением твоей работы.

Это single-context C-код без HAL. Он не потокобезопасен, не ISR-safe и не является готовым драйвером передачи. Firmware и hardware этим эталоном не тестируются.
