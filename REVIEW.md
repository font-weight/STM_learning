## Польза для обучения и сохранение курса

1. Практика доступна из договора частот и L05. Учащийся сам выбирает PSC/ARR и вводит прогноз входной частоты таймера, частоты после PSC и наличия/частоты периодических update-событий. Неполный или некорректный ввод не открывает результат.
2. Изменение условий очищает прогноз; изменение ответа скрывает прежнюю сверку. Обратная связь показывает расхождение с номинальной арифметикой и предлагает объяснить его перед измерением.
3. Нет автоподбора делителей, генерации прошивки, оценки компетентности или автоматического завершения лабораторной. Практика не обращается к сети, плате или хранилищу прогресса. Единственная внешняя ссылка открывается по действию учащегося.
4. Шаг явно необязательный. Сохранены **14 лабораторных и 48 основных часов**, требования к оборудованию, gates и предпосылки. `course-schema.json`, модель прогресса, runtime читателя, рубрика оценки и шаблон журнала не изменены. Для проверки «по памяти» предлагается закрыть помощник.

## Техническая корректность

Проверены два фиксированных профиля: HSI 8 МГц без PLL с делителями шин `/1` и HSE 8 МГц → PLL ×9 с APB1 `/2`, APB2 `/1`. Расчёт корректно различает PCLK и timer clock, учитывает `PSC+1`, `ARR+1`, 16-битные пределы и блокировку счётчика при ARR=0. Для TIM1 явно требуется RCR=0; установившийся внутренний edge-aligned счёт вверх и разрешённые update events названы предпосылками. Переходы preload, дополнительные UG, gated/slave/one-pulse и center-aligned режимы исключены. Для повторяющихся PWM-фронтов отдельно нужны разрешённый PWM1-выход и `1 ≤ CCR ≤ ARR`. Эти ограничения согласуются с [RM0008 Rev 21](https://www.st.com/resource/en/reference_manual/rm0008-stm32f101xx-stm32f102xx-stm32f103xx-stm32f105xx-and-stm32f107xx-advanced-armbased-32bit-mcus-stmicroelectronics.pdf), §7.2, главы 14–15.

Назначение L05 **PA1 / TIM2_CH2 без remap** сохранено. Разрядность TIM1/TIM2/TIM3 и соответствие выводов проверены по [DS5319](https://www.st.com/resource/en/datasheet/stm32f103c8.pdf). Выбор профиля в форме не объявляется переключением платы, а расчёт не объявляется измерением, частотой callback или аппаратным зачётом. Правила низковольтного стенда сохранены.

## Что остаётся непроверенным

- Настоящий desktop/mobile browser, клавиатурные переходы и объявления screen reader; восстановление страницы и прогресса реальным браузером. Ранее запуск браузера был заблокирован; обходные попытки в этом ревью не предпринимались.
- ARM build полного generated-проекта, Flash/verify, SWD, физические сигналы, точность генераторов и аппаратные gates.
- Учебный прогон с человеком, эффективность упражнения и оценка фактического времени курса.
- Сетевая доступность всех внешних ссылок для пользователя. DS5319 прочитан по официальному адресу; RM0008 проверен по сохранённой копии Rev 21, поскольку средство веб-чтения не приняло большой PDF. Статический тест ссылки не гарантирует её доступность в будущем.
- Совпадение опубликованного сайта или GitHub с этим комплектом. Адрес в README указывает на личный доступ через ChatGPT; публикация именно этой редакции требует отдельной проверки итоговых файлов/commit.

**Вывод:** v2.1 можно выпускать как необязательное учебное дополнение с указанными границами проверки. Следующее содержательное доказательство должно приходить из настоящего браузерного и стендового прогона; успешная арифметическая сверка не заменяет их.
