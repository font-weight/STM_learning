# Проверки учебного комплекта

Дата проверки: 9 октября 2026 года. Редакция курса: v2. Этот документ описывает проверки авторов комплекта, а не результаты выполнения лабораторных учащимся.

## Выполнено в среде подготовки

| Проверка | Результат | Что это подтверждает |
|---|---|---|
| Digital helpers, оптимизированная сборка и ASan/UBSan | PASS | Контракты чистой C-логики на компьютере |
| UART console с тестовым HAL | PASS | Сценарии восстановления RX, владения TX и сохранения маски IRQ в модели |
| Buffering release-check | PASS | 6 тестов эталона; исходный ученический каркас ожидаемо не проходит тест |
| CSV checker | 36 тестов PASS | Синтетические записи, границы сессий, достаточность строк/длительности и cadence; не физический сигнал |
| Проверка IOC/linker/ELF | 47 тестов PASS | Синтетические форматы и негативные случаи; не реальная сборка CubeMX |
| L11 sample guard | 9 сценариев / 121 проверка PASS | Чистая C-логика времени, последовательности и состояния; без ADC/DMA/IWDG |
| Чувствительность тестов к дефектам | 12 guard + 6 buffering мутаций отвергнуты | Заранее внесённые ошибки обнаруживаются тестами; это не доказательство отсутствия других ошибок |
| Фрагмент L06 из учебного текста | PASS в ограниченном профиле | sequence=0, начальное состояние, граница и перенос tick; история в полный цикл 2^32 мс явно вне контракта |
| Модель прогресса и минимальные DOM-контракты | 31 тест PASS | Отметки, повторение, импорт/экспорт, recall-маршрут; модель DOM не является браузером |
| Markdown renderer, защита и поиск связанных документов | 34 теста PASS | Детерминированная сборка, циклы, границы путей/размеров и негативные сценарии |
| Python/JavaScript syntax | PASS | Синтаксическая корректность проверяемых файлов |
| Структура курса и локальные ссылки | PASS | 14 модулей, зависимости, контрольные пункты, доступные локальные пути/якоря |
| Сборка index.html и структурная проверка ссылок | PASS | Автономный HTML собран без отсутствующих исходных документов |

Компилятор host-тестов: GCC 14.2. Проверки ASan/UBSan не заменяют анализ гонок и испытание периферии. LeakSanitizer отключён из-за ограничений среды; цифровые примеры не используют динамическую память.

## Не выполнено

- Полная сборка generated CubeMX-проекта ARM-компилятором: не выполнена. В среде подготовки нет arm-none-eabi-gcc.
- Прошивка, SWD-отладка и измерения на физической Blue Pill: не выполнены. Плата и измерительные приборы не подключены.
- Проверка отображения и взаимодействия в настоящем браузере, на Android или iPhone: не выполнена. Запуск браузерного теста в доступной среде заблокирован; статические проверки не объявляются браузерными.
- Проверка всех внешних ссылок на доступность в момент открытия пользователем не гарантируется. Структурная проверка ссылок не делает сетевой запрос к каждой странице.

- Эффективность курса на настоящем учащемся и точность оценки 48 часов не измерялись. Исследования методов обучения не заменяют такую проверку.

Поэтому готовность учебного комплекта не означает аппаратную валидацию всех примеров. В лабораторных отдельно указаны наблюдения и критерии, которые нужно получить на своей плате.

## Как повторить проверки

Требования к host-инструментам приведены в [TOOLCHAIN](docs/TOOLCHAIN.md). Из корня репозитория:

```sh
bash scripts/check_all.sh
```

Для полного набора нужны также Node.js и инструменты host-сборки; для обычного чтения курса они не требуются. Если система не поддерживает санитайзеры, можно выполнить `SANITIZE=0 bash scripts/check_all.sh`. Тогда ASan/UBSan **пропущены**, а не пройдены; отметьте это в своём отчёте.

Тест `release-check` специально проверяет, что незаполненный `student.c` остаётся учебным заданием. Его результат EXPECTED RED не надо исправлять копированием эталона. После собственной реализации запускайте `make exercise-check` в `examples/host-buffering`.

Дополнительная браузерная проверка описана в [site/README.md](site/README.md). Её наличие в репозитории не означает, что она была выполнена авторами.

### Проверка стартового маршрута GPIO

`python3 tests/check_digital_startup.py`: нативные mock-проверки вариантов PC13/PB0 и положительный/отрицательный контроль удаления секций GNU linker. Это не исполнение startup STM32, не ARM-сборка и не испытание платы.

### Необязательные инструменты браузера

Регистрация, аргументы и маршруты `read_course_curriculum`, `navigate_course`, `start_course_recall` проверены только нативными registry/DOM test doubles. Они не читают личный прогресс, не отмечают занятия выполненными и не вызывают ИИ. Проверка в настоящем поддерживаемом WebMCP-контексте не выполнена; в неподдерживаемом браузере обычный курс продолжает работать.
