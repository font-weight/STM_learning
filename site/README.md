# Офлайн-читатель курса

Весь учебный текст редактируется в `docs/` и `course-schema.json`. HTML не является вторым источником содержания: он автоматически собирается из этих файлов. Не правьте скомпилированный `index.html` вручную.

## Сборка

Из корня репозитория:

```sh
python3 scripts/build_site.py
```

Нужен только Python 3.10 или новее; сетевые запросы и сторонние пакеты не используются. Результат — один `index.html` со встроенными стилями, JavaScript и содержанием. Откройте его обычным двойным щелчком, сервер не требуется. Связанные файлы примеров и исходный Markdown остаются рядом в репозитории.

Сборщик также включает Markdown, на который ведут локальные ссылки из курса: например, README упражнений и руководства к инструментам. Вложенные переходы и циклы обрабатываются детерминированно. Такие вспомогательные материалы открываются внутри читателя по ссылке; список основных материалов не засоряется техническими README. Ссылки на C, Python и другие исходные файлы остаются файловыми: для них храните папки репозитория рядом с `index.html`.

Обход ограничен 128 Markdown-файлами, 2 000 000 байт на файл и 8 000 000 байт суммарно. Читаются только начальные документы и достижимые из них Markdown-ссылки. Пути за пределы корня, включая симлинки, отклоняются; ссылки внутри кода и экранированного HTML не запускают включение файлов. Отсутствующий связанный Markdown останавливает обычную сборку. Идентификатор сборки зависит от исходного текста, схемы, компилятора и интерфейса, а не от времени запуска.

Для сборки из другой папки:

```sh
python3 scripts/build_site.py --root /path/to/repository
```

`--allow-missing` допустим только для временной проверки интерфейса. Обычная сборка завершается ошибкой, если отсутствует хоть одна обязательная лаборатория или документ из схемы.

## Работа с лабораторией

У лаборатории два режима: «Материал» и «Без подсказок». Во втором режиме основной текст, подсказки и критерии скрыты. Вопросы берутся из `review_prompts` той же схемы курса. Сначала сформулируйте свою версию вслух или в журнале, затем нажмите «Сверить с материалом». Переключение режимов не меняет отметки и не выставляет оценку. Маршруты `#recall/L00` и обычные `#module/L00` работают офлайн; возврат и история браузера используют обычные hash-ссылки.

«Зафиксировать результат» ведёт к ручным отметкам. Критерий завершения и формат прогресса остаются прежними. Ритм повторений +1/+3/+7/+21 — практический исходный план, а не обязательный или оптимальный для всех интервал.

Основной текст имеет размер 16 px, код — 13 px в том числе на телефоне. «Перенос строк» меняет только отображение блока, скопированный текст остаётся исходным. Прокручиваемые блоки кода и таблицы доступны с клавиатуры; оглавление по умолчанию свёрнуто в компактном макете. Тема доступна также в окне прогресса на телефоне.

## Что сохраняется

- Отметки практики и отдельная самооценка без подсказок
- Дата завершения и исходный план повторений на дни 1, 3, 7 и 21
- Фактические даты повторений вместе с прежними плановыми датами
- Предпочтение светлой/тёмной темы

Прогресс не отправляется на сервер и не является оценкой навыка. Если повторение просрочено, следующее назначается с исходным интервалом 2, 4 или 14 дней от реального повторения. Будущее повторение нельзя отметить заранее. Снятие отметки завершения удаляет связанный план повторений.

Формат сохранения по-прежнему `stm32-practice-progress`, версия 1. Миграция не нужна: прежние экспорты, отметки и история повторений сохраняют совместимость. В окне прогресса отдельно показано, доступна ли запись в браузере или отметки временные. Сообщение об экспорте подтверждает только подготовку файла; браузер должен действительно сохранить его.

`localStorage` на `file://` зависит от браузера и пути файла. Некоторые браузеры или режимы приватности блокируют его. Экспорт JSON — переносимая резервная копия. Импорт проверяет формат, версию, курс, известные модули, отметки, даты и историю. Замена прогресса и сброс требуют подтверждения. Несовместимые сохранённые данные автоматически не перезаписываются. В этом случае отдельная кнопка «Скачать исходные данные» сохраняет их неизменённую копию; обычный экспорт сохраняет текущие временные отметки.

## Markdown

Поддерживаются заголовки, абзацы, блоки кода с ограждением, вложенные списки, списки задач, цитаты, обычные ссылки, таблицы GFM, локальные изображения и простое выделение. Внешние изображения становятся ссылками, чтобы страница не зависела от сети.

Ограниченно поддерживается raw HTML: отдельная строка `<a id="safe-id"></a>` с идентификатором из латинских букв, цифр, `_` и `-`. Она преобразуется в пустой безопасный якорь. Также поддерживается закрытый блок `<details>` без атрибутов с последующей строкой `<summary>Текст</summary>` и закрывающим `</details>`: подсказка скрыта до открытия, всё содержимое проходит обычное безопасное преобразование. Атрибуты и произвольный HTML не разрешены. Остальной raw HTML экранируется. Ссылки на Markdown внутри `docs/` становятся встроенными маршрутами; фрагменты работают и между документами. Сложные HTML-блоки, таблицы с объединёнными ячейками, плагины Markdown, LaTeX и reference-style links не поддерживаются. Для формул используйте текст или блок кода.

## Проверки

Без сторонних зависимостей:

```sh
node --test tests/state.test.cjs
python3 tests/test_build.py
python3 tests/check_site.py
```

`state.test.cjs` включает чистые тесты модели и минимальный DOM-контракт для настоящих обработчиков `app.js`: переключение режима, неизменность сохранений v1, закрытые подсказки, якоря, перенос кода, импорт/экспорт/отмена, повреждённое или недоступное хранилище. Этот тестовый DOM не вычисляет CSS, не эмулирует реальный браузер и не заменяет визуальную, мобильную или screen-reader проверку.

Последняя команда проверяет итоговую сборку и её локальные ссылки. Это статическая проверка, она не проверяет внешний сайт по ссылке или физическую плату.

Отдельный браузерный набор использует Python Playwright и установленный Chromium:

```sh
python3 tests/browser_smoke.py
# Или для разрешённого HTTP-превью:
python3 tests/browser_smoke.py --url http://127.0.0.1:8000/
```

Скрипт проверяет маршруты, поиск, фильтры, отметки, экспорт/импорт, отмену сброса, несовместимый JSON, защиту сохранённой новой версии, отказ хранилища, отказ clipboard, 320-пиксельную ширину и отсутствие неожиданных сетевых запросов. Сохраняет снимки и JSON-отчёт. Установка Playwright не нужна пользователю курса. Запуск браузерного скрипта требует среды, в которой разрешён запуск Chromium; наличие файла скрипта не означает, что тест выполнен.

## Структура

- `site/index.template.html` — семантическая оболочка
- `site/styles.css` — адаптивный интерфейс, тёмная тема и печать
- `site/state.js` — чистая модель прогресса и валидация импорта
- `site/app.js` — навигация, режим без подсказок, поиск, доступные элементы управления
- `scripts/build_site.py` — безопасный компилятор Markdown и single-file сборка
- `course-schema.json` — стабильные ID, маршрут, оценки времени и критерии

Никаких внешних CDN, шрифтов, аналитики, API-ключей, чата с ИИ или сервис-воркера. Кнопка копирования имеет fallback; длинный код и таблицы прокручиваются внутри своих блоков. Уровень доступности не сертифицирован: применены семантические landmarks, labels, keyboard focus, skip-link, live-status и reduced-motion.

## Необязательная совместимость браузера

При наличии `document.modelContext.registerTool` доступны три ограниченных действия: общие сведения о программе, переход к материалу и открытие режима воспроизведения по памяти. Они не читают личный прогресс, не отмечают задания выполненными, не импортируют и не сбрасывают данные. Это не подключение ИИ к прошивке или внешнему API. В обычном браузере без такого интерфейса курс работает как раньше. Проверки выполнены на нативных test doubles; реальный WebMCP-контекст не проверен.
